Endless Runner

Description

Endless Runner is a learning-based gameplay project developed in Unreal Engine, focused on understanding core game development systems such as character movement, obstacle interaction, and scoring mechanics.

The project was built by following structured tutorials and extended through hands-on implementation, helping build a strong foundation in Blueprint scripting, game loop design, and player control systems.

The gameplay features continuous forward movement where the player must avoid obstacles using jumping, sliding, and lane switching, while collecting coins and power-ups to increase score. The project demonstrates how core gameplay mechanics are structured and executed in a real-time environment.

Key Features

  • 🏃 Endless runner gameplay system
  • 🎮 Character controls (jump, slide, lane switching)
  • ⚡ Continuous forward movement logic
  • 🧩 Obstacle spawning and collision system
  • 💰 Coin collection and scoring system
  • 🧲 Basic power-up system (coin magnet)
  • 📘 Developed as a learning project from tutorials

System Flow

🎮 Input

  • Player input for jump, slide, and lane switching
  • Continuous forward movement handled automatically

⚙️ Core Logic

  • Blueprint-based character movement system
  • Obstacle spawning and collision detection
  • Coin collection with score tracking
  • Power-up activation (magnet effect)

🔄 Gameplay Flow

  • Start → Run → Avoid Obstacles → Collect Coins → Score Update → Repeat

Tech

Unreal Engine Blueprints Game Loop Design Learning Project
