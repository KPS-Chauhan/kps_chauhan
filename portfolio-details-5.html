Description

Death Camera & Invisibility System is a gameplay mechanic developed in Unreal Engine using Blueprints, focused on player detection, camera-based interaction, and dynamic state changes.

The system detects the player using line tracing from a camera perspective. When the player enters the detection range, the system triggers a response such as activating ragdoll physics, simulating a “death” or failure state.

Additionally, the project includes an invisibility mechanic, where material-based changes are applied dynamically to the player, allowing toggling between visible and invisible states.

Key Features

  • 🎥 Camera-based player detection system
  • 🎯 Line trace detection for visibility checks
  • 💀 Automatic ragdoll activation on detection
  • 👻 Dynamic invisibility system using materials
  • ⚙️ Event-driven gameplay response
  • 🎮 Real-time interaction with environment

System Flow

🎮 Detection

  • Camera performs line trace toward player
  • Checks if player is within detection range

⚙️ Core Logic

  • If player is detected → trigger ragdoll state
  • If player is hidden/invisible → detection fails
  • Material switching controls visibility state

🔄 Gameplay Flow

  • Player enters range → Detection → State Change → Response

Technical Highlights

  • Use of line tracing for real-time detection
  • Integration of physics (ragdoll) with gameplay events
  • Dynamic material manipulation for invisibility
  • Blueprint-based event-driven system design
