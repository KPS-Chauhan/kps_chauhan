Runner

Description

Runner is a hyper-casual mobile game developed using Unity and C#, focused on delivering quick, engaging gameplay through simple mechanics and responsive controls. The project was built within a short development cycle, emphasizing rapid prototyping and core gameplay design.

The gameplay revolves around continuous movement and obstacle avoidance, where the player must navigate through a dynamic path while collecting coins and avoiding obstacles. The experience is designed to be intuitive and fast-paced, aligning with hyper-casual design principles.

Developed as a compact project, the game demonstrates strong fundamentals in game loop design, input handling, and scoring systems, while maintaining performance and simplicity suitable for mobile platforms.

Key Features

  • 🎮 Simple one-touch / input-based control system
  • ⚡ Fast-paced hyper-casual gameplay loop
  • 🧩 Obstacle avoidance mechanics
  • 💰 Coin collection and scoring system
  • 📱 Mobile-optimized performance
  • 🚀 Rapid development (built within 2 days)

System Flow

🎮 Input

  • Player input (tap / click) triggers movement
  • Continuous forward motion handled automatically

⚙️ Core Logic

  • Obstacle spawning and collision detection
  • Coin collection system with score tracking
  • Game state management (start → play → end)

🔄 Gameplay Flow

  • Start Game → Player Movement → Avoid Obstacles → Collect Coins → Reach End → Score Display
