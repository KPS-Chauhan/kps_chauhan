Climbing System

Description

Climbing System is a C++-based character movement system developed in Unreal Engine, focused on extending the default movement capabilities to support advanced climbing mechanics.

The project explores how custom movement systems can be built by modifying and extending the Character Movement Component, enabling the character to detect climbable surfaces and transition into climbing states dynamically.

Developed as a learning and implementation project, it demonstrates a strong understanding of movement logic, vector mathematics, animation systems, and real-time environment interaction.

Key Features

  • 🧗 Custom climbing movement system
  • ⚙️ Extended Character Movement Component (C++)
  • 🧩 Ledge detection and surface alignment
  • 🎮 Smooth transition between ground and climbing states
  • 🎬 Root motion-based climbing animations
  • 🧠 Environment-aware climbing logic

System Flow

🎮 Input

  • Player movement and climb trigger input

⚙️ Core Logic

  • Surface detection using traces and collision checks
  • Vector math (dot product / cross product) for alignment
  • Custom movement mode for climbing state
  • State transitions between walking, falling, and climbing

🎬 Animation System

  • Root motion animations integrated with movement logic
  • Control Rig used to refine and adapt animations
  • IK setup for hand and foot placement
  • Motion Warping for accurate positioning during climbs

Technical Highlights

  • Extension of Unreal’s Character Movement Component in C++
  • Custom algorithms for ledge and surface detection
  • Use of vector mathematics for directional calculations
  • Clean and extensible system design

What I Learned

  • Extending character movement systems using C++
  • Applying dot product and cross product in gameplay logic
  • Using Control Rig to modify and adapt animations
  • Integrating root motion into gameplay systems
  • Implementing IK for realistic character interaction
  • Using Motion Warping for dynamic movement adjustments
  • Designing scalable and maintainable gameplay systems
