TripleSix

Description

Triple Six is a first-person psychological horror game released on the Epic Games platform, focused on delivering a tense, immersive, and unpredictable player experience. The game is designed around atmosphere, environmental storytelling, and event-driven horror sequences.

The core experience revolves around exploration, suspense, and reactive events, where players navigate through dark environments while uncovering hidden triggers that dynamically alter the game world. Instead of scripted linear gameplay, Triple Six uses systems that respond to player movement and interaction to create fear and uncertainty.

Built using Unreal Engine 5, the project utilizes a Blueprint-driven architecture to implement gameplay systems, interaction logic, and horror event triggers. The game is also prepared for real-world deployment, having been packaged and released through the Epic Games ecosystem.

Key Features

  • 👁️ First-person psychological horror experience
  • 🌑 Atmospheric lighting and sound design for tension building
  • ⚡ Event-driven horror system (dynamic scares & triggers)
  • 🎮 Exploration-based gameplay with environmental storytelling
  • 🧠 Non-linear progression using trigger-based systems
  • 🚀 Released on Epic Games platform (production-ready build)

System Flow

🎮 Input

  • Player input handled via UE5 Input System
  • Movement (WASD)
  • Camera control (Mouse)
  • Interaction (E / key-based triggers)

⚙️ Core Logic

  • Blueprint-based interaction system
  • Line trace / overlap detection for usable objects
  • Trigger-based event system (Box Collisions)
  • Dynamic activation of horror elements

👻 Gameplay Flow

  • Exploration → Trigger Detection → Horror Event → Progression
  • Events include sound cues, light flickers, and environmental changes
  • Player-driven pacing creates unpredictable horror experience
