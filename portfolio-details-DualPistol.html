Dual Pistol Multiplayer Combat Prototype — Unreal Engine 5 / C++

A multiplayer third-person combat prototype developed in Unreal Engine 5 using C++. The project focuses on understanding how gameplay systems, input, animation and multiplayer networking work together.

Key Features

  • 🔫 Independent left and right pistol controls
  • 🔥 Single and simultaneous dual-pistol firing
  • 🎯 Camera-based aiming
  • 🎯 Line-trace based hit detection
  • 🎮 Independent weapon input-state management
  • 🌐 Multiplayer replicated gameplay
  • 📡 Server and Multicast RPC communication
  • 🔄 RepNotify-based state handling
  • 🎬 Dual-weapon animation integration
  • 🎯 Dynamic crosshair and weapon spread

Multiplayer Networking

A major focus of this prototype was making the weapon system function correctly in a multiplayer environment.

  • Client-server architecture
  • Server-authoritative gameplay
  • Actor ownership
  • Property replication
  • Server RPCs
  • Multicast RPCs
  • RepNotify
  • Client/server state synchronization
Example Network Flow

Client Input → Server RPC → Server Gameplay Logic → Replicated State → Other Clients

Input & Weapon System

The firing system uses two independent weapon states instead of treating both pistols as a single weapon.

  • Left pistol firing
  • Right pistol firing
  • Both pistols firing simultaneously
  • Independent button release handling
  • Continuous firing of the remaining active weapon

Example:

Left Fire + Right Fire → Both Fire
Release Left → Right Continues

Aiming & Hit Detection

  • Camera-based aiming
  • Line-trace based targeting
  • Hit detection using trace results
  • Integration between aiming and weapon firing
Camera Aim → Trace → Hit Result → Weapon Gameplay

Animation System

The dual-pistol system required animation integration so weapon animations could work together with character locomotion.

  • Animation Montages
  • Montage Slots
  • Linked Animation Layers
  • Layered Blend Per Bone
  • Upper-body weapon animation
  • Lower-body locomotion integration

Crosshair System

  • Dynamic weapon spread
  • Screen-space crosshair calculations
  • Multiple crosshair elements
  • Dynamic spread based on weapon state

Challenges & Debugging

A significant part of the project involved debugging the interaction between gameplay, networking, input and animation systems.

  • Debugging dual-fire animation playback
  • Handling independent left/right firing states
  • Maintaining firing when one input is released
  • Debugging client/server synchronization
  • Debugging RPC execution and replicated states
  • Resolving upper-body and lower-body animation conflicts
  • Debugging character rotation caused by animation blending
  • Correcting crosshair positioning and spread calculations
