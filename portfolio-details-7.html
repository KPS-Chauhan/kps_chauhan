Drone Simulator

Description

Drone Simulator is a simulation-focused project developed as my major academic project, aimed at building a foundational understanding of drone movement, control systems, and real-time input handling within Unreal Engine.

The project focuses on basic flight mechanics and control logic, allowing users to pilot a drone using input-driven movement. While not fully physically accurate, the system demonstrates how directional control, lift approximation, and stabilization can be implemented in a real-time environment.

Built using Unreal Engine and Blueprint-based systems, the simulator emphasizes core concepts such as input mapping, vector-based movement, and continuous update loops. The project serves as an early exploration into simulation systems and real-time control behavior.

Key Features

  • 🚁 Basic drone movement system
  • 🎮 Input-based controls (throttle, pitch, yaw, roll)
  • ⚙️ Simplified lift and movement approximation
  • 🌍 Collision handling and environment interaction
  • 🧠 Real-time control response using Blueprint logic
  • 📘 Focus on learning core simulation concepts

System Flow

🎮 Input

  • User input mapped to drone controls
  • Throttle (basic upward force)
  • Pitch (forward/backward movement)
  • Yaw (rotation)
  • Roll (side movement)

⚙️ Core Logic

  • Input values converted into directional movement
  • Basic force/velocity adjustments for lift and motion
  • Simplified stabilization to keep the drone controllable
  • Continuous update loop for smooth response

🔄 Simulation Flow

  • Input → Movement Calculation → Apply Velocity → Position Update
  • Real-time adjustments based on user control

Tech

Unreal Engine 5 Blueprints Basic Physics Logic Vector Mathematics Real-Time Input System
