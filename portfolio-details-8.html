Traversal Parkour System

Description

Traversal Parkour System is a modular plugin developed in Unreal Engine using Blueprint, designed to provide a reusable and scalable framework for parkour-style traversal mechanics.

The system was built by applying concepts learned through structured tutorials and extending them into a plugin-based architecture, focusing on reusability, clean organization, and system-level design.

It enables characters to interact dynamically with the environment using advanced tracing techniques, animation systems, and state-driven logic, allowing actions such as climbing, vaulting, and ledge detection based on real-time conditions.

Key Features

  • 🧩 Plugin-based modular traversal system
  • 🏃 Environment-aware parkour mechanics (vault, climb, ledge grab)
  • ⚙️ Multiple tracing techniques (Line, Sphere, Capsule, Box)
  • 🧠 State management using Gameplay Tags
  • 🎬 Animation Montages and Notifies integration
  • 📦 Data-driven setup using DataAssets

System Flow

🎮 Input

  • Player movement and interaction input

⚙️ Core Logic

  • Environment detection using tracing systems
  • Vector math for movement direction and alignment
  • Decision system selects appropriate traversal action
  • Gameplay Tags manage states and transitions

🎬 Animation System

  • Animation Montages triggered per traversal action
  • Motion Warping for dynamic positioning
  • Inverse Kinematics (IK) for accurate interaction

Technical Highlights

  • Designed as a reusable plugin for easy integration
  • Clean system organization using helper functions
  • Separation of logic, animation, and configuration
  • Scalable architecture for future expansion
