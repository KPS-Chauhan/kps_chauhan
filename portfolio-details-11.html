Parkour Pulse

Description

Parkour Pulse is a fast-paced, movement-driven gameplay prototype built in Unreal Engine 5.4, focused on delivering fluid, responsive, and skill-based parkour mechanics. The project explores advanced character locomotion systems by blending precision control with dynamic environmental interaction.

The experience is centered around momentum, timing, and player flow, allowing seamless chaining of parkour actions such as vaulting, wall-running, climbing, and ledge-grabbing. Every movement is designed to feel responsive while maintaining a sense of weight and realism.

Built entirely using a Blueprint-only architecture, the project extends the Advanced Locomotion System (ALS) with custom traversal mechanics. It also includes Steam integration, enabling overlay support, build deployment readiness, and a foundation for achievements and platform-level systems.

Key Features

  • ⚡ Fluid parkour system with smooth transitions
  • 🎮 Momentum-based movement and player flow
  • 🧠 Advanced animation blending using ALS
  • 🧩 Dynamic environment interaction system
  • 🌐 Steam integration (overlay + deployment pipeline)
  • 🔧 Fully Blueprint-based system design

System Flow

🎮 Input

  • Player input handled via UE5 Input System
  • Movement (WASD)
  • Camera control (Mouse)
  • Jump / Parkour actions (context-based)

⚙️ Core Logic

  • Blueprint-driven movement system
  • Surface detection using line traces
  • Context-based traversal decisions
  • State-driven animation transitions

🔄 Gameplay Flow

  • Movement → Surface Detection → Parkour Action → Flow Continuation
  • Dynamic chaining of actions based on player timing

Tech

Unreal Engine 5.4 Blueprints Advanced Locomotion System (ALS) Parkour Plugin Steamworks Integration
